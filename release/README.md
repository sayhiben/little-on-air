# Current project release

The complete manufacturing release is [Little ON AIR enclosure v2.13](little-on-air-enclosure-v2.13/README.md).

- [Download the complete ZIP](little-on-air-enclosure-v2.13.zip)
- [Open the three-plate Bambu Studio project](little-on-air-enclosure-v2.13/bambu-studio/on-air-v213-X1C-all-plates.3mf)
- [Read the build guide](little-on-air-enclosure-v2.13/guides/BUILD-AND-ASSEMBLY.md)
- [Review all parts and materials](little-on-air-enclosure-v2.13/BOM.csv)

The release includes current production STLs, acrylic artwork, calibration SVGs, Fusion/STEP CAD, assembly and wiring guides, validation records and a firmware source snapshot. Optional laminate parts are kept separate from the selected printed backing. Older development iterations remain under `hardware/enclosure/`; see its [revision history](../hardware/enclosure/REVISION-HISTORY.md).

The enclosure is v2.13; the packaged firmware is independently versioned v0.1.2 and currently drives onboard RGB LEDs only. External NeoPixel output remains a firmware task.
