# Firmware source snapshot

Version **0.1.2**, commit `ce3745f0ddc3b3d8bd56da88aaa2f05fe750a1ab`. This is the preserved older snapshot, not a newly selected firmware release. The source ZIP includes build, flashing and pairing instructions and LICENSE. It uses onboard RGB PWM only; this snapshot does not implement the four external NeoPixels. Read [firmware status](../guides/FIRMWARE-STATUS.md) and the enclosure USB operating procedure before flashing. No UF2/ELF or build toolchain is included.
