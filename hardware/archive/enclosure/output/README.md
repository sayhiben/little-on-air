# Generated development files

For a complete current build, use the [curated v2.13 release](../../../release/little-on-air-enclosure-v2.13/README.md).

This directory retains historical fabrication packages, fit iterations, CAD intermediates, slicer outputs and inspection reports. Its contents are development history and regeneration inputs; do not combine similarly named parts from different subdirectories for a new build.

The current release selects the v2.13 frame/housing/captive guides, unchanged v2.8 backing/retainers/reset, shared laser artwork and the completed three-plate project. The [revision history](../REVISION-HISTORY.md) identifies older packages. Their paths are preserved because the generation scripts and earlier records refer to them.
