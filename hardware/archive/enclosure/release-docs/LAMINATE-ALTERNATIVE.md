# Optional laminate backing — omit for the selected printed insert

These files are retained as an alternative, separate from the production print set:

- `03-optional-laminate-FRONT-engrave-and-cut.svg`: front-facing, unmirrored artwork for confirmed laser-safe black-over-white laminate, nominal **1.6 mm** thick.
- `81-laminate-front-spacer.stl` and `82-laminate-rear-shim.stl`: both spacer rings required for that alternative stack. Print black at 0.10 mm layers and 100% infill, in the supplied orientation.

Use the laminate **instead of** printed backing 03. Do not combine the rings with the printed backing. Verify the actual laminate thickness and rear cushioning against the unchanged acrylic/retainer stack, and verify dry-fit registration before tightening. Use the laminate manufacturer's proven laser settings; the acrylic RF settings are not transferable.

The common three-plate Bambu project contains the selected black-and-white PLA+ backing and intentionally excludes these alternative parts. These unchanged alternative meshes are included for completeness; they have not been added to or sliced in that project.
